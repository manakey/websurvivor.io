# SURVIVE

見下ろし型サバイバー系アクションゲーム（ブラウザ動作、HTML5 Canvas）。
移動するだけで自動攻撃、レベルアップでスキル選択、10分生存でクリア。

## 遊び方
- PC: `W A S D` または矢印キーで移動
- スマホ: 画面左下のスティックで移動

## 公開方法（GitHub Pages）
1. このリポジトリを GitHub に push
2. Settings → Pages → Branch を `main` / `/(root)` に設定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## ローカル確認
`index.html` をブラウザで直接開くだけで動作します。
